# Calculator
A simple calculator built using **HTML, CSS, and JavaScript**.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Percentage (%)
- Delete (DEL)
- All Clear (AC)
- Responsive design

## Live Demo
https://ak16calculator.netlify.app/

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the live demo or run `index.html` in your browser.
2. Enter numbers using the calculator buttons.
3. Choose an operator and press `=` to get the result.
